# Constitution

## Princípio I — Segurança por Default

Nenhuma implementação deve armazenar credenciais ou secrets
diretamente no código ou documentação.

## Princípio II — Least Privilege

Componentes devem possuir somente as permissões necessárias
para executar suas responsabilidades.

## Princípio III — Dados Sensíveis

Dados confidenciais devem ser minimizados, protegidos e
substituídos por dados sintéticos em ambientes de desenvolvimento
quando possível.

## Princípio IV — Reprodutibilidade sem Exposição

Uma implementação deve ser reproduzível sem exigir que
credenciais ou detalhes sensíveis de infraestrutura sejam
armazenados no repositório.

## Princípio V — Evidência

Decisões devem ser sustentadas por evidências verificáveis.

## Princípio VI — Contexto Mínimo

Cada agente deve receber somente o contexto necessário para
executar sua tarefa corretamente.
