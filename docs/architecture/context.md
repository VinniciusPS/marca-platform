# Contexto do Sistema

## Propósito
O sistema permite que empresas gerenciem reservas e pagamentos de serviços,
além de acompanhar métricas operacionais e financeiras.

## Atores
- **Usuário Operacional**: cria reservas e registra pagamentos
- **Gestor**: acompanha métricas e resultados
- **Provedor de Pagamento Externo**: autoriza transações financeiras

## Sistemas Internos
- Sistema de Reservas
- Sistema de Pagamentos
- Sistema de Analytics

## Integrações Externas
- Provedor de Pagamento

## Visão Geral
O sistema é acessado por usuários internos da empresa e se integra a um
provedor externo para processamento de pagamentos.
